## 1. 何をする道具か

`ax+b=c` のような等式を、指定された文字について解く練習をする。
情報Iのプログラミングで変数の式を組み替えるときの土台にあたる。

生徒はブラウザで解いて自己採点する。先生はA4のプリントとして印刷して配れる。
**サーバーには何も送らない。** 採点の記録だけは、その端末のブラウザの中に残す（9章）。

## 3. 出題

### 3-1. 問題バンク

`data/questions.ts` に **40問**。1問は次の5つを持つ。

| 項目 | 中身 |
|---|---|
| `id` | 1〜40 の通し番号 |
| `prompt` | 問題文。数式は `\( \)` で囲んだ LaTeX |
| `choices` | 選択肢の LaTeX 文字列。**4つ**（正解1・誤答3） |
| `answer` | 正解の LaTeX 文字列。`choices` のどれかと完全に一致する |
| `explain` | 解説。数式は `\( \)` で囲む |

扱う型と問題数は次のとおり。文字式のまま答えるものが中心で、数値だけの答えになる問題は無い。

| 型 | 例 | 問題数 |
|---|---|---|
| 移項するだけ | `3x-5y+7=0`、`ax=by+c` | 11 |
| かっこを展開する | `A=3(2x+y)`、`y=2(x+3)-4` | 9 |
| 積・商 | `P=4xy`、`\dfrac{a}{bc}=d` | 8 |
| 分数係数・分数方程式 | `V=\dfrac{1}{3}Sh`、`\dfrac{2x+1}{3}=y` | 8 |
| 通分・逆数が要る | `\dfrac{1}{x}+\dfrac{1}{y}=\dfrac{1}{a}` | 4 |

うち **8問は実際の公式**（円周 `L=2\pi r`、円柱の体積、台形の面積、三角形の面積、
速さ、平均、並列抵抗、比例式）。文字だけの練習に終わらないようにしてある。
**円周率 `\pi` は変数ではなく定数として評価する**ので、記述式でも `r=\dfrac{L}{2\pi}` と書ける。

誤答3つは、**実際に起こる間違いを1つずつ**当てている。符号を取り違えたもの、
分子と分母を入れ替えたもの、割るところを掛けたもの、係数や指数を落としたもの。

**4つの選択肢は値としてすべて異なる。** 2つの選択肢がたまたま同じ値になっていると、
当てずっぽうの当たる確率が上がってしまうため、テストで常時検査している（5-3）。

### 3-2. 抽出

- バンク40問を毎回シャッフルし、先頭から出題数だけ取る。**同じ問題は重複しない**（実測）。
- さらに **問題ごとに選択肢の並び順もシャッフルする**。正解の位置は固定されない。
- 抽出は次の3つのときに走る。
  - ページを開いたとき
  - 「出題を更新」を押したとき
  - 「別の問題に変える」を押したとき
- 「やり直し」では抽出し直さない（同じ問題が残る。実測で確認）。

### 3-3. 出題数

入力欄は `type="number"`、既定値は 10。「出題を更新」を押したときの値を次の順で丸める
（`lib/quiz.ts` の `clampQuestionCount`）。

1. **空欄や数として読めない値は、既定の10問に戻す**
2. 小数は切り捨て
3. 1 未満は 1、40 超（＝バンクの件数超）は 40 に丸める
4. **丸めた値を入力欄にも書き戻す**（表示と実際の問題数がずれないようにする）

実測した結果は次のとおり。

| 欄に入れた値 | 出題数 | 押した後の欄の表示 |
|---|---|---|
| `0` / `-5` | 1 | `1` |
| `3.7` | 3 | `3` |
| `999` | 40（バンク全問） | `40` |
| 空欄 | 10 | `10` |
| `abc` | 10 | `10` |

## 4. 解答方式

タブで「択一式」「記述式」を切り替える。**切り替えると、それまでの解答と採点結果は
すべて消える**（得点・正解バッジ・解説の自動展開もリセットされる）。

### 4-1. 択一式（既定）

- 選択肢4つをラジオボタンで縦に並べる。行全体が `<label>` なので、文字のどこを
  押しても選べる。
- 選べるのは1問につき1つ。採点後は `disabled` になり選び直せない。

### 4-2. 記述式

- MathLive の `<math-field>` を1問に1つ置く。プレースホルダは `例: x=(5y-7)/3`。
- `math-virtual-keyboard-policy="onfocus"` なので、欄をタップ／クリックすると
  数式キーボードが出る。分数・変数はそこから入れる。
- 入力は LaTeX 文字列として保持される。
- 「記述式の答え方」の枠が、記述式のときだけ問題の上に出る。
  数式キーボードの出し方／**求める文字から `x=` のように書くこと**／
  **値が同じなら、項の順序・展開・通分・小数の違いは正解になること**。

## 5. 採点

「採点する」を押した時点の解答を、その場ですべて突き合わせる。
無解答は不正解として数える。**未解答があっても警告は出ない**し、確認もされない。

### 5-1. 択一式の判定

選んだ選択肢の文字列が `answer` と **完全に一致**すれば正解。
選択肢は `answer` から作られているので、ここで取りこぼしは起きない。

### 5-2. 記述式の判定

**式を実際に評価して、値が同じかどうかで判定する。**（`lib/equivalence.ts`）
文字列の見た目は問わない。手順は次のとおり。

1. 生徒の入力と `answer` の両方を LaTeX から素の式に均す
   （`\dfrac`→`\frac`、`\frac{A}{B}`→`((A)/(B))`、`^{2}`→`^(2)`、`\cdot` `\times`→`*`、
   `\left` `\right` と空白は削除）
2. `=` で2つに割り、再帰下降で式として読む。`4xy` や `2(x+1)` のように記号なしで
   並んだものは掛け算として読む
3. **左辺が正解と同じ変数1文字であることを求める**（5-2-1）
4. 両辺に出てくる変数へ、同じ値を入れて右辺どうしを比べる（5-2-2）

どちらかが式として読めなかったときだけ、従来の文字列一致（`normalizeAnswer`）に任せる。
**読めない入力で判定が甘くなることはない**（従来と同じ厳しさに戻るだけ）。

#### 5-2-1. 左辺の決まり

- 「`x` について解け」なので、**`x=` から書くことを求める**。右辺だけ書いても正解にしない。
- 違う文字について解いていたら、不正解にしたうえで
  「`y` について解いた形（`y=` …）で答えてください。」と画面に出す。
- **大文字と小文字は別の変数**として扱う（`X` と `x` は別物）。
- 右辺に求める文字自身が残っている式（`x=2x-6y-1`）は「解けていない」ので不正解にする。

#### 5-2-2. 値の比べ方

- 変数には **0 から離れた値**（絶対値 1.25〜8.75）を入れる。正負を混ぜて符号の違いを拾う。
- **8組そろうまで代入を試す**（上限64回）。分母が0になるなど評価できない組は捨てて引き直す。
- 8組すべてで一致すれば正解。1組でも外れたらその場で不正解。
- 一致とみなす**相対誤差は 1e-9**。
- 評価できる組が3つ未満だった式は、判定材料が足りないとみなして文字列一致に任せる。
- **乱数は固定の種から作る。** 同じ解答を何度採点しても結果は必ず同じになる。

### 5-3. 記述式で通る書き方・弾かれる書き方（実測）

`lib/equivalence.test.ts` で常時検査している。**46件すべて通っている**（2026-08-05）。

正解にする書き方（`x=\dfrac{5y-7}{3}` が正解の問題ほか）:

| 生徒の入力 | 正解データ |
|---|---|
| `x=\frac{5y-7}{3}` / `x=(5y-7)/3` | `x=\dfrac{5y-7}{3}` |
| `x=\dfrac{-7+5y}{3}`（項の順序） | 同上 |
| `x=\dfrac{5}{3}y-\dfrac{7}{3}`（分配した形） | 同上 |
| `x=\dfrac{7-5y}{-3}`（分母を負に） | 同上 |
| `x=\dfrac{10y-14}{6}`（**約分していない形**） | 同上 |
| `a=3b+2` / `a=2+b\cdot3` / `a=2+3\times b` | `a=2+3b` |
| `x=pr-pq` / `x=(r-q)p`（展開・因子の順序） | `x=p(r-q)` |
| `x=n+\dfrac{k}{m}` / `x=\dfrac{k+mn}{m}`（通分） | `x=\dfrac{k}{m}+n` |
| `x=t+0.5y`（**小数**） | `x=t+\dfrac{y}{2}` |
| `x=\dfrac{-ay}{a-y}`（分子分母を同時に符号反転） | `x=\dfrac{ay}{y-a}` |
| `x=\dfrac{1}{4}\cdot\dfrac{P}{y}` | `x=\dfrac{P}{4y}` |

不正解にする書き方:

| 生徒の入力 | 理由 |
|---|---|
| `x=\dfrac{7-5y}{3}` / `x=\dfrac{5y+7}{3}` | 値が違う（符号の誤り） |
| `x=\dfrac{k+n}{m}` | 値が違う（割る順序の誤り） |
| `x=2x-6y-1` | 右辺に `x` が残っている＝解けていない |
| `\dfrac{5y-7}{3}` | `x=` を書いていない |
| `X=\dfrac{5y-7}{3}` | 大文字・小文字が違う |
| `y=…`（別の文字について解いた） | 求める文字が違う。理由を画面に出す |

**問題バンク40問の点検もテストに含めている。**

- 40問すべての `answer` が式として読め、左辺が変数1文字であること
- 正解そのものを入力すれば必ず正解になること
- 選択肢がちょうど4つで、正解をちょうど1つ含むこと
- **120個ある誤答の選択肢を入力したとき、1つも正解に漏れないこと**
- **4つの選択肢が、値として互いにすべて異なること**

### 5-3-1. この方式で許すこと

値が同じであれば通すので、次は**正解として扱う**。

- 約分していない形（`x=\dfrac{10y-14}{6}`）
- `0.5` と `\dfrac{1}{2}`

ただし**正解にしたうえで模範解答も見せる**（6章）。約分や簡単な形を強制はしないが、
自分の書き方と模範解答を見比べられるようにしてある。

### 5-4. 得点とコメント

`得点 / 出題数` と正解率（四捨五入した整数％）を出し、得点に応じたコメントを1つ出す。

| 条件 | コメント |
|---|---|
| 全問正解 | 満点！移項と係数処理が完璧です。 |
| 80%以上 | とても良いです。符号と割り算の扱いを再確認すると満点が見えます。 |
| 50%以上 | 基礎はできています。移項時の符号ミスに注意！ |
| それ未満 | まずは移項→係数で割るの手順を丁寧に練習しましょう。 |

境目は `Math.ceil(出題数 × 0.8)` と `Math.ceil(出題数 × 0.5)` で決まる。
10問なら8問以上・5問以上。

## 6. 採点後の表示

| 場所 | 出るもの |
|---|---|
| 各問の右上 | 「正解」（緑）／「不正解」（赤）のバッジ |
| 択一式の選択肢 | 正解の行に緑の枠と背景。選んだのが誤りならその行に赤の枠と背景 |
| 記述式の入力欄 | 正解なら緑、不正解なら赤の枠と背景 |

| 不正解の理由が書き方のとき | その2行のあいだに一言入る（「`y` について解いた形（`y=` …）で答えてください。」／「求める文字から「= 」で続けて書いてください。」） |

## 8. 印刷

「印刷（A4）」で下からシートが出る。チェックは3つ。

| チェック | 既定 | 効果 |
|---|---|---|
| 氏名・学年欄を含める | オン | **用紙の先頭に1回だけ**「等式の変形テスト ／ 氏名：… ／ 学年：… 組：… 番：…」を出す |
| 解答を含める | オフ | 各問の選択肢の下に「解答: 〜」を出す |
| 解説を含める | オフ | 各問の下に解説の枠を出す |

チェックの状態は `document.body` のクラス（`print-show-answers` など）として持ち、
印刷用CSSがそれを見て表示を切り替える。「印刷する」を押すと 150ms 後に
`window.print()` を呼ぶ。**チェックの状態はシートを閉じても保持される**が、
ページを再読み込みすると既定に戻る。

### 8-1. 紙面（実測）

`@page { size: A4; margin: 12mm }`。headless Chrome の `--print-to-pdf` で実際に
出して確かめた（2026-08-05）。

| 設定 | 10問での枚数 | 1ページあたり |
|---|---|---|
| 既定（氏名欄のみ） | **3枚** | 3〜4問 |
| 解答・解説つき | **5枚** | 2問 |

紙面で守っていること。

- **選択肢は2列に並べる**（`.equation-choices` を印刷時だけ grid 2列にする）。
  4択を縦1列のまま出すと1ページ2問にしかならず、10問で6枚になっていた。
- 問題カードは `break-inside: avoid`。ページの途中で1問が割れない。
- ヘッダー・タブ・出題数・ボタン・採点結果・記録・使い方は消える。
  **サイトのフッター（運営者情報などのリンク）も消す。**
- 影・角丸・薄い背景色は落とし、白地に細い罫線だけにする。数式の色は黒に固定。
- 見出しは「等式の変形テスト」の1行だけ。「問題バンクからランダム出題」の説明は消す。

### 8-2. 直した不具合（2026-08-05）

- **氏名欄が問題に重なっていた。** `position: fixed` で用紙の下端に置いていたが、
  実際には本文の上に重なって印刷されていた。用紙の先頭に1回だけ出す形に変えた。
- **サイトのフッターが配布プリントに印刷されていた。**
- **1ページに2問しか入らず、10問で6枚**になっていた。

### 8-3. 確かめていないこと

- 実際の紙に出したときの濃さ・罫線の見え方（PDFまでは確認した）。
- 記述式のまま印刷したときの数式入力欄の見え方。記述式は画面で解く前提の作りで、
  印刷して手書きさせる使い方は想定していない。
- iPad・スマートフォンの実機での数式キーボードの操作感。

## 9. 記録

**サーバーへの送信は一切ない。** 記録はその端末のブラウザの `localStorage` にだけ残す
（`lib/history.ts`、キーは `equation-transformation:history:v1`）。

### 9-1. 残すもの・残さないもの

残すのは1回の採点につき次の4つだけ。

| 項目 | 中身 |
|---|---|
| `at` | 採点した時刻（ミリ秒） |
| `mode` | `choice` / `input` |
| `total` / `correct` | 出題数と正解数 |
| `wrongIds` | 間違えた問題の id |

**名前・学年・組・番号は持たない。** 誰の記録かは分からない。
**直近5回だけ**残し、古いものから捨てる。

### 9-2. 画面での使われ方

- 記録が1件でもあれば、問題の上に「この端末に残っている記録」として
  `4/5　記述式　8月5日 14:29` の形で新しい順に並べる。
- 間違えた問題があれば「間違えた◯問をもう一度」のボタンが出る。押すと
  **その問題だけを出題する**（新しい回で間違えたものが先。同じ問題は1回だけ）。
- 「記録を消す」でいつでも全部消せる。

### 9-3. 壊れていても動く

- `localStorage` が読めない・書けない環境（プライベートモード等）では、
  記録を諦めて通常どおり動く。例外は外に出さない。
- 保存内容が壊れていたり、形の違う項目が混ざっていたら、その項目だけ捨てる。

### 9-4. それでも残らないもの

解いている途中の解答は残らない。ページを閉じるか再読み込みすると、
解答は消えて新しい問題になる（記録だけが残る）。
